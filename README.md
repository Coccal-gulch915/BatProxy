## 🧩 Understanding the features

BatProxy manages your connection through several smart systems.

Automatic Failover: If a server becomes slow, the software detects this change. It switches your connection to a faster server without interrupting your work. You remain protected during this transition.

Cloudflare Workers: We use global network infrastructure to route your data. This creates a bridge between your computer and the websites you visit. This method masks your original IP address from the websites you visit.

Encryption: All data moving through the tunnel stays private. The software uses industry standards to wrap your information in protective layers. This prevents prying eyes from seeing your activity.

## 🔧 Troubleshooting common issues

If you encounter problems, check these items first.

The software does not open: Ensure your antivirus software does not block the application. Sometimes, security tools mistake new programs for threats. Add BatProxy to your list of trusted applications in your security settings.

The connection stays yellow: A yellow light means the software searches for a server. Wait for one minute. If it remains yellow, check your home internet connection. Turn your router off and on to refresh your network path.

Slow speeds: Cloudflare provides many locations. If the speed drops, disconnect and reconnect. The software will search for a closer server during the new connection phase.
